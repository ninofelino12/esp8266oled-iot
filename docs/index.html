Konfigurasi Koneksi ESP32

Masukkan alamat IP lokal ESP32 Anda (misal: http://192.168.1.105/api/weather) yang mengembalikan format JSON.

Contoh Respon JSON ESP32:

{"mac": "24:6F:28:A1:B4:C8", "lat": -6.59714, "lng": 106.80603, "temperature": 28.4, "humidity": 76.2, "pressure": 1011.5, "windSpeed": 12.0, "lux": 4500}

Contoh Data Log JSON ESP32

Pilih preset atau edit JSON di bawah untuk dimuat langsung ke grafik & dashboard

*Memuat JSON akan menjeda mode simulasi otomatis
